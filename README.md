## 📌 Featured Projects

### 👻 GhostPort-ESP32

A low-cost ESP32-based network-tunnelling client created for embedded-networking research, authorised security testing, IoT management, and ethical-hacking education.

It allows an ESP32 to act as a lightweight communication bridge between an authorised local service and a remote tunnelling server.

[View GhostPort-ESP32](https://github.com/Midhun884/GhostPort-Esp32)

### 🌑 ShadowPort

A lightweight reverse-tunnelling server and client system designed to provide controlled remote access to authorised devices and services located behind NAT or restricted networks.

[View ShadowPort](https://github.com/Midhun884/shadowport)

### 📡 ESP32 MQTT Controller

An ESP32-based controller that communicates with cloud and local services using MQTT, allowing remote device control, configuration, and automation.

[View ESP32 MQTT Controller](https://github.com/Midhun884/esp32-mqtt-controller)

### 👁 Flask Object Detection

A Flask-based computer-vision application for performing object detection and displaying AI-generated results through a web interface.

[View Flask Object Detection](https://github.com/Midhun884/flask_object_detection)
