## 📌 Featured Projects

### 👻 GhostPort-ESP32

A low-cost ESP32-based network-tunnelling client created for embedded-networking research, authorised security testing, IoT management, and ethical-hacking education.

It allows an ESP32 to act as a lightweight communication bridge between a local service and a remote tunnelling server.

### 🌑 ShadowPort

A lightweight reverse-tunnelling system designed to provide controlled remote access to authorised devices and services located behind NAT or restricted networks.

### 📡 ESP32 MQTT Controller

An ESP32-based controller that communicates with cloud and local services using MQTT, allowing remote device control, configuration, and automation.

### 👁 Flask Object Detection

A Flask-based computer-vision application for performing object detection and displaying AI-generated results through a web interface.
